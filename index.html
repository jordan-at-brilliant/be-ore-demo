Feedback setup

Votes are committed directly to feedback/queue.jsonl in the demo repo. You need a GitHub fine-grained token with Contents: Read & write on jordan-at-brilliant/be-ore-demo.

Create one at github.com/settings/tokens → Fine-grained → Repository access: jordan-at-brilliant/be-ore-demo → Permissions → Contents: Read and write.

If no token is set, votes are queued locally and you can export them as JSON.
